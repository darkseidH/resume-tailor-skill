# Profile Map Template

Copy into your private workspace when ready to save a map. Paths below illustrate the suggested `.local/profile-map.md` layout; replace them with actual locations. Source files can stay in their existing narrative format.

## Private Workspace

- Workspace root: `.` (relative to this map)
- Application output directory: `applications/` (relative to this map)

## Sources

| Stable source ID | Path relative to this map, or absolute path | Coverage |
|---|---|---|
| experience-notes | `profile/experience.md` | Current and previous roles, contributions and projects |
| education-notes | `profile/education.md` | Qualifications, coursework, academic projects and certifications |
| skills-notes | `profile/skills.md` | Skills, supporting examples and languages |

One source may cover all areas. Remove unused rows and record actual coverage rather than creating empty source files. Report missing mapped sources before using the map.

## Preferences

- CV language: ask if unknown (English or French).
- Template: ask if unknown; initial rendering uses classic A4.

## Mapping Review

Confirm the mapped sources and private destinations with the user. Save answers and unresolved coverage, conflicts, and ownership questions in the private application/onboarding record. Propose new reusable facts as exact canonical edits at each completed clarification topic; after approval, write and reread them. Report actual update status rather than treating answer storage as a profile edit.
