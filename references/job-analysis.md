# Assess a Job Against Evidence

Preserve the full supplied job text before interpretation. Extract atomic requirements with IDs; distinguish required from preferred and retain qualifiers such as production use, years, proficiency, location, and eligibility. Mark unstated details unknown rather than inferring them.

Compare each requirement with the complete profile, not only the last CV. Use the classifications in [data-contracts.md](data-contracts.md). Cite fact IDs and their source references. Transferable experience supports a partial match with a specific explanation; keyword overlap alone does not prove a strong match. A criterion needing a qualification or eligibility condition cannot be overridden by technical fit.

Prioritize clarification by consequence: eligibility and conflicting dates, ownership or proficiency affecting important claims, then details improving positioning. State why the answer matters and ask one focused question. An absent Docker entry is unknown, not a gap; ask about actual use. If the answer is “never used it,” record a confirmed gap without inventing experience.

Use [the match report template](../templates/match-report.md). Summarize strong and partial matches, confirmed gaps, unknowns, and evidence-backed weak points separately. Explain practical steps: clarify an existing example, omit an unsupported claim, prepare an interview explanation, or learn a skill for future roles. Learning suggestions must not become current CV qualifications.

For new reusable facts obtained during analysis, complete the [profile-update checkpoint](profile-updates.md) at the end of the clarification topic. The match report must distinguish application answers from verified edits to the reusable profile. Review this analysis with the user before generation. If an answer cannot be obtained, retain uncertainty and omit unsupported claims. Generation can proceed when remaining uncertainty does not prevent a truthful CV and profile updates have been applied, declined, or explicitly deferred. Do not assign a numerical match score or make unsupported hiring predictions.
